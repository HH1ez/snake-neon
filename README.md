# snake-neon
🐍 Змейка Неон — классическая аркада в новом стиле.  🎮 Что внутри:  7 уникальных карт (лабиринт, крест, порталы).  Телепорты (проход сквозь стены).  Золотые яблоки и щит, который спасает от смерти.  Редактор карт — можешь нарисовать свой уровень.  Работает на телефоне (нужно повернуть экран) и на ПК.
